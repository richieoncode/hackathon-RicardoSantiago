# Balanza

Simulador de mediación por voz para practicar lo más difícil del oficio: ganar la confianza de dos personas, ser imparcial y cuidar la legalidad al mismo tiempo.

Creado por Ricardo Santiago Vázquez, persona facilitadora certificada, con Claude Code para el Hackathon Lawgic.

## Cómo funciona
Medias, con tu voz o por escrito, una sucesión ficticia en una empresa familiar regia. Elena y Andrés responden a lo que dices, recuerdan la sesión y cambian de emoción. La sala mide confianza, imparcialidad, legalidad y avance, sugiere el siguiente paso y cierra con línea de tiempo emocional y reporte de competencias.

## Tecnología
- HTML, CSS y JavaScript, sin dependencias.
- Claude Code para el diseño y la construcción.
- Gemini para interpretar a los personajes y evaluar.
- ElevenLabs para voces y transcripción.
- Supabase para funciones, almacenamiento y tabla de puntajes.

## Aviso
Caso y personajes ficticios. Herramienta educativa; no es asesoría legal. No compartas datos reales. Las llaves privadas viven fuera de este repositorio.
